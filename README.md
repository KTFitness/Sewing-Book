# Kirsty's Sewing Book

A phone web app for sewing: makes with needles and machine settings, inspo, patterns, fabric and notions stash, machines and measurements. Hosted on GitHub Pages.

- `data/threadloop.json` holds the Threadloop pattern stash (names, designers, types, fabric and design-detail tags).
- `tl/` holds the Threadloop pattern pictures, 50 to a sheet.
- `data/seed.json` holds entries Claude adds (machines, makes). The app copies new ones onto the phone once.
- Everything added in the app is saved on the phone only. Use Backup in the More tab to keep a copy.
